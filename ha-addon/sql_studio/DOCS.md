# SQL Studio for Home Assistant

Interactive web-based SQL query runner, schema browser, and database management tool integrated directly into your Home Assistant sidebar.

---

## Features
* **Zero-Config Auto-Login**: Automatically connects to your local PostgreSQL 16 server.
* **Database Switcher**: Easily switch between `emporia_energy` and `homeassistant`.
* **SQL Query Command**: Write any `SELECT`, `INSERT`, or aggregate query with live results.
* **Exporting**: Download query results directly as CSV or SQL.
* **Dark Mode**: High-contrast dark theme matching Home Assistant.
